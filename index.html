Por que estudar Estatística e Probabilidade?

A Estatística transforma dados em informação: resume, compara e permite decidir com base em números. A Probabilidade mede a chance de algo acontecer e é a base para prever resultados e quantificar incertezas. Juntas, aparecem em controle de qualidade, finanças, saúde, produção industrial e tecnologia.

Como usar: cada assunto tem 7 blocos (O que é? · Para que serve? · Fórmula · Entendendo a fórmula · Exemplo resolvido · Interpretação · Resumo). Use a busca ou os cards para chegar direto ao tema.

1º Bimestre · Estatística Descritiva e Probabilidade

Distribuição de Frequências

O que é?

Uma tabela que agrupa os dados brutos em classes (intervalos) e mostra quantas observações caem em cada uma. Quando há poucos valores diferentes, pode-se listar cada valor; quando há muitos, agrupa-se em classes.

Para que serve?

Resumir dezenas ou centenas de números em uma visão compacta, mostrando onde os dados se concentram e onde são raros.

Fórmula

AT = Xmáx − Xmín  |  k ≈ 1 + 3,322·log₁₀(n)  |  h = AT / k
fr = fi / n  |  Fac = soma acumulada de fi  |  Frac = Fac / n

Entendendo a fórmula

AT: amplitude total (maior − menor valor). k: número de classes (Sturges), arredondado. h: amplitude de cada classe, arredondada para cima para que as classes cubram todos os dados. fi: frequência absoluta (contagem). fr: frequência relativa (proporção). Fac: acumulada, quantos dados há até aquela classe.

Exemplo resolvido

40 revendedores e as unidades compradas (Atividade 1). Menor valor = 6, maior = 39.

  1. AT = 39 − 6 = 33.
  2. k = 1 + 3,322·log₁₀(40) = 1 + 3,322·1,602 = 6,32 ⇒ k = 6.
  3. h = 33 / 6 = 5,5 ⇒ h = 6 (6 × 6 = 36 ≥ 33, cobre todos os dados).
  4. Classes [a, b) (inclui o limite inferior, exclui o superior), começando em 6; contar os dados de cada uma.

Se usar k = 7, h = 33/7 = 4,71 ⇒ 5; a regra de Sturges é um guia, e k = 6 ou 7 são aceitáveis. Confira a convenção pedida pelo professor.

Interpretação

A classe 18 ⊢ 24 concentra 40% dos revendedores. Pela Frac, 70% compraram menos de 24 unidades. Poucos compram muito: só 1 (2,5%) chegou a 36 ou mais.

Resumo

Calcule AT → k → h → monte as classes → conte (fi) → derive fr, Fac e Frac. A soma de fi deve ser n e a de fr deve ser 1.

Gráficos Estatísticos: Histograma e Polígono

O que é?

O histograma é um gráfico de barras encostadas, uma por classe, com altura igual à frequência. O polígono de frequências é uma linha que une os pontos (ponto médio da classe, frequência).

Para que serve?

Enxergar a forma da distribuição: onde está o pico, se é simétrica ou se tem cauda longa para um lado.

Fórmula

Ponto médio: Xi = (limite inferior + limite superior) / 2

Entendendo a fórmula

No histograma, o eixo horizontal mostra os limites das classes e o vertical, fi. No polígono, use Xi no eixo horizontal e acrescente uma classe vazia (fi = 0) em cada extremidade para a linha “fechar” no eixo.

Exemplo resolvido

Dados da tabela do assunto 1: fi = 4, 8, 16, 7, 4, 1.

Pontos do polígono: (3, 0), (9, 4), (15, 8), (21, 16), (27, 7), (33, 4), (39, 1), (45, 0).

Interpretação

O pico está em 18 ⊢ 24 e a cauda se me alonga à direita (assimetria positiva): a maioria compra volumes moderados e poucos compram muito. Diferença: o histograma mostra cada classe como área; o polígono mostra a tendência e facilita comparar várias distribuições no mesmo gráfico.

Resumo

Histograma = barras por classe. Polígono = linha pelos pontos médios, com classes vazias nas pontas. Ambos usam as mesmas frequências.

Medidas de Tendência Central: Média Aritmética

O que é?

É o valor que representa o “centro” dos dados: a soma de todos os valores dividida pela quantidade deles.

Para que serve?

Resumir um conjunto em um único número típico, como a média de unidades compradas ou a nota média de uma turma.

Fórmula

Dados brutos: x̄ = Σxi / n
Dados em classes: x̄ = Σ(fi · Xi) / n

Entendendo a fórmula

Σ = somatório; n = total de observações; Xi = ponto médio da classe; fi = quantas observações a classe tem (peso). Use a primeira quando tiver os dados originais e a segunda quando só tiver a tabela.

Exemplo resolvido

Dados brutos (40 revendedores): Σxi = 822, então x̄ = 822 / 40 = 20,55.

Dados agrupados: Σfi·Xi = 4·9 + 8·15 + 16·21 + 7·27 + 4·33 + 1·39 = 36 + 120 + 336 + 189 + 132 + 39 = 852, logo x̄ = 852 / 40 = 21,3.

A diferença (20,55 × 21,3) existe porque o agrupamento usa o ponto médio no lugar de cada valor real. Nos próximos cálculos, usamos 21,3 para ser coerente com a tabela.

Interpretação

Em média, cada revendedor adquiriu cerca de 21 unidades no mês. Como a distribuição tem cauda à direita, valores muito altos puxam a média para cima.

Resumo

Média = soma ÷ quantidade. Em tabelas de classes, multiplique cada ponto médio pela sua frequência.

Medidas de Dispersão

O que é?

Medem o quanto os dados se afastam da média. Variância e desvio padrão dão o afastamento em unidades absolutas; o coeficiente de variação dá o afastamento relativo (em %).

Para que serve?

Duas turmas podem ter a mesma média e comportamentos muito diferentes. A dispersão mostra se os dados são homogêneos ou espalhados, e o CV permite comparar conjuntos com unidades ou médias distintas.

Fórmula

s² = Σfi(Xi − x̄)² / (n − 1) = [Σfi·Xi² − n·x̄²] / (n − 1)
s = √s²  |  CV = (s / x̄) · 100%

Entendendo a fórmula

Eleva-se ao quadrado cada desvio (Xi − x̄) para que positivos e negativos não se anulem. Divide-se por n − 1 quando os dados são uma amostra (caso dos 40 revendedores) e por n quando são a população inteira. O desvio padrão volta à unidade original.

Exemplo resolvido
  1. x̄ = 21,3 (assunto 3).
  2. Σfi·Xi² = 4·81 + 8·225 + 16·441 + 7·729 + 4·1089 + 1·1521 = 20 160.
  3. n·x̄² = 40 · 453,69 = 18 147,6.
  4. s² = (20 160 − 18 147,6) / 39 = 2 012,4 / 39 = 51,60.
  5. s = √51,60 = 7,18 unidades.
  6. CV = 7,18 / 21,3 = 33,7%.

Se tratar os dados como população (÷ n): s² = 50,31; s = 7,09; CV = 33,3%. Use a convenção da sua aula.

Interpretação

Os revendedores se afastam, em média, cerca de 7 unidades da média. Uma regra prática (varia conforme o autor): CV < 15% baixa dispersão, 15% a 30% média, > 30% alta. Aqui a dispersão é alta: as compras são pouco homogêneas.

Resumo

Variância → desvio padrão (raiz) → CV (desvio ÷ média). Amostra: n − 1. Quanto maior o CV, mais heterogêneos os dados.

Correlação e Regressão Linear

O que é?

A correlação mede o quanto duas variáveis variam juntas. A regressão linear encontra a reta ŷ = a + b·x que melhor descreve essa relação, permitindo estimar y a partir de x. O diagrama de dispersão é o gráfico de pontos (x, y) que mostra a relação visualmente.

Para que serve?

Verificar se, por exemplo, a produção industrial cresce com o tempo e prever a produção em um ano que não foi medido.

Fórmula

r = [nΣxy − ΣxΣy] / √{[nΣx² − (Σx)²] · [nΣy² − (Σy)²]}
b = [nΣxy − ΣxΣy] / [nΣx² − (Σx)²]  |  a = ȳ − b·x̄  |  ŷ = a + b·x

Entendendo a fórmula

r varia de −1 a +1. r > 0: correlação positiva (x sobe, y sobe). r < 0: negativa. r ≈ 0: nula (sem relação linear). Quanto mais perto de ±1, mais forte (referência comum: |r| ≥ 0,7 forte). b é a inclinação (quanto y muda por unidade de x) e a é o intercepto. Subtrair 1984 dos anos (x′ = ano − 1984) simplifica as contas.

Exemplo resolvido

Produção (t) de 1980 a 1988: 34, 36, 36, 38, 41, 42, 43, 44, 46. Com x′ = −4, …, 4 e n = 9:

Σx = 0 · Σy = 360 · Σxy = 90 · Σx² = 60 · Σy² = 14 538 · x̄ = 0 · ȳ = 40.

  1. r = (9·90 − 0·360) / √[(9·60 − 0)(9·14 538 − 360²)] = 810 / √(540 · 1 242) = 810 / 818,95 = 0,9891.
  2. b = 810 / 540 = 1,5; a = 40 − 1,5·0 = 40. Reta: ŷ = 1,5x + 40 (x = ano − 1984).
  3. Para 1979: x = 1979 − 1984 = −5 ⇒ ŷ = 1,5·(−5) + 40 = 32,5 t.

Interpretação

r = 0,99 indica correlação positiva muito forte; r² ≈ 0,978, ou seja, cerca de 98% da variação da produção é explicada pelo tempo. A produção aumentou, em média, 1,5 t por ano. Atenção: 1979 está fora do período observado (extrapolação), então a estimativa é menos confiável.

Resumo

Dispersão → r (força e sentido) → reta ŷ = a + bx → estimativas. Correlação não prova causa.

Probabilidade e Tabelas de Contingência

O que é?

Espaço amostral (Ω) é o conjunto de todos os resultados possíveis; evento é um subconjunto de Ω. A probabilidade de um evento é a razão entre os casos favoráveis e os casos possíveis. Uma tabela de contingência cruza duas características e conta quantos casos há em cada combinação.

Para que serve?

Calcular chances a partir de dados reais, como a probabilidade de sortear uma pessoa com determinado perfil.

Fórmula

P(A) = n(A) / n(Ω)  |  P(Aᶜ) = 1 − P(A)
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Entendendo a fórmula

“ou” = união (somar e descontar a interseção para não contar duas vezes). “e” = interseção (a célula onde as duas características se cruzam na tabela). “não” = complementar. Se os eventos não têm elementos em comum, P(A ∩ B) = 0.

Exemplo resolvido

30 mulheres, por estado civil e cor dos cabelos:

Estado civilLoiraMorenaRuivaTotal
Casada58316
Solteira2417
Viúva0112
Divorciada3115
Total1014630
  • A (casada): 16/30 = 8/15.
  • B (não loira): 1 − 10/30 = 20/30 = 2/3.
  • C (nem morena nem ruiva = loira): 10/30 = 1/3.
  • D (viúva): 2/30 = 1/15.
  • E (solteira ou casada): 7/30 + 16/30 − 0 = 23/30 (sem interseção).
  • F (loira e casada): 5/30 = 1/6.
  • G (morena e solteira): 4/30 = 2/15.
  • H (viúva e ruiva): 1/30.

Interpretação

Mais da metade do grupo (53,3%) é casada. A chance de sortear uma loira casada (1/6 ≈ 16,7%) é menor que a de sortear uma casada qualquer (8/15), pois “e” restringe o evento.

Resumo

Probabilidade = favoráveis ÷ possíveis. “Ou” soma (menos a interseção), “e” é a célula da tabela, “não” é 1 − P.

Probabilidade de Eventos Dependentes

O que é?

Dois eventos são dependentes quando o resultado do primeiro altera as chances do segundo. É o caso típico de sorteios sem reposição: o número sorteado não volta ao conjunto.

Para que serve?

Calcular a chance de sequências de sorteios, como rifas, extrações de cartas ou peças retiradas de um lote.

Fórmula

P(A ∩ B) = P(A) · P(B | A)

Entendendo a fórmula

P(B | A) lê-se “probabilidade de B dado que A ocorreu”. Como A já aconteceu, o total e os casos favoráveis são recalculados. Se houvesse reposição, os eventos seriam independentes e P(A ∩ B) = P(A)·P(B).

Exemplo resolvido

Rifa de 15 números, dois prêmios sorteados um de cada vez; você comprou 3 números. G₁ = ganhar o 1º prêmio, G₂ = ganhar o 2º.

  1. P(G₁) = 3/15.
  2. Ganhou o 1º com um dos seus números, restam 14 números no sorteio, dos quais 2 são seus: P(G₂ | G₁) = 2/14.
  3. P(G₁ ∩ G₂) = 3/15 · 2/14 = 6/210 = 1/35 ≈ 2,86%.

Interpretação

Há cerca de 2,9% de chance de levar os dois prêmios. Se o mesmo número pudesse ser sorteado de novo (com reposição), seria 3/15 · 3/15 = 4%: a retirada sem reposição reduz a chance.

Resumo

Sem reposição → multiplique, atualizando total e favoráveis a cada etapa.

Variáveis Aleatórias Discretas

O que é?

Uma variável aleatória associa um número a cada resultado de um experimento aleatório. É discreta quando assume valores contáveis (0, 1, 2…). A função de probabilidade informa P(X = x) para cada valor possível.

Para que serve?

Descrever o comportamento de um fenômeno com resultados incertos e calcular o valor médio esperado e a variabilidade.

Fórmula

E(X) = Σ x·P(x)  |  Var(X) = E(X²) − [E(X)]²  |  DP = √Var(X)
E(aX + b) = a·E(X) + b  |  Var(aX + b) = a²·Var(X)

Entendendo a fórmula

E(X) é a média ponderada pelas probabilidades. E(X²) = Σ x²·P(x). Em transformações, somar uma constante b desloca a média mas não altera a variância; multiplicar por a multiplica a média por a e a variância por a². A soma das probabilidades deve ser 1.

Exemplo resolvido

Urna A: 3 brancas e 2 pretas. Urna B: 5 brancas e 1 preta. Retira-se uma bola de cada; X = número de bolas brancas. a) X ∈ {0, 1, 2}.

b) P(branca em A) = 3/5; P(branca em B) = 5/6 (as retiradas são independentes).

02/5 · 1/61/15 = 0,0667
13/5·1/6 + 2/5·5/6 = 3/30 + 10/3013/30 = 0,4333
23/5 · 5/61/2 = 0,5

c) P(0 < X ≤ 2) = 13/30 + 15/30 = 0,9333; P(X > 1) = P(X = 2) = 0,5.

d) E(X) = 0 + 13/30 + 2·(1/2) = 1,4333. E(X²) = 13/30 + 4·(1/2) = 2,4333. Var = 2,4333 − 1,4333² = 0,3789. DP = √0,3789 = 0,6155.

Em média, saem 1,43 bolas brancas por rodada, com desvio de 0,62. O valor 2 é o mais provável (50%).

Resumo

Liste valores → calcule P(x) → verifique que somam 1 → E(X), Var, DP → aplique as regras de transformação.

Distribuição Binomial

O que é?

Modela o número de sucessos em n tentativas repetidas. Características: n fixo; cada tentativa tem só dois resultados (sucesso ou fracasso); tentativas independentes; probabilidade p de sucesso constante.

Para que serve?

Situações como “quantos, entre 20 títulos, serão pagos com atraso?” ou “quantas peças defeituosas em um lote pequeno?”.

Fórmula

P(X = k) = C(n, k) · pk · qn−k,   C(n, k) = n! / [k!(n − k)!]
q = 1 − p  |  E(X) = n·p  |  Var(X) = n·p·q

Entendendo a fórmula

n: nº de tentativas; k: nº de sucessos desejado; p: chance de sucesso; q: chance de fracasso. “Sucesso” é o que a pergunta quer contar, mesmo que seja algo ruim. No máximo k: P(X ≤ k) soma de 0 até k. No mínimo k: P(X ≥ k) = 1 − P(X ≤ k − 1). Exatamente k: uma só parcela.

Exemplo resolvido

20% dos títulos são pagos com atraso; 20 títulos pagos no dia. n = 20, sucesso = atraso, p = 0,2, q = 0,8.

a) No máximo dois com atraso: P(X ≤ 2) = P(0) + P(1) + P(2)

  • P(0) = 0,8²⁰ = 0,0115
  • P(1) = 20 · 0,2 · 0,8¹⁹ = 0,0576
  • P(2) = 190 · 0,2² · 0,8¹⁸ = 0,1369

Soma ≈ 0,206 (0,2061 sem arredondar as parcelas).

b) No mínimo três pagos sem atraso: agora sucesso = “sem atraso”, p = 0,8. P(Y ≥ 3) = 1 − P(Y ≤ 2). Y ≤ 2 equivale a 18 ou mais títulos atrasados, algo da ordem de 3·10⁻¹¹. Logo P ≈ 1.

Interpretação

Há cerca de 20,6% de chance de no máximo 2 atrasos em 20 títulos. Esperam-se E(X) = 20·0,2 = 4 atrasos. Já ter ao menos 3 títulos em dia é praticamente certo.

Resumo

Identifique n, p e o que é “sucesso”. Use a fórmula para cada k e some (ou use o complementar) em “no máximo/mínimo”.

Distribuição de Poisson

O que é?

Modela o número de ocorrências em um intervalo (tempo, área, comprimento) quando os eventos acontecem de forma independente e com taxa média constante λ. Diferente da binomial, não há um número fixo de tentativas.

Para que serve?

Clientes por hora, chamadas por minuto, defeitos por metro de tecido, acidentes por mês.

Fórmula

P(X = k) = e−λ · λk / k!  |  E(X) = λ  |  Var(X) = λ

Entendendo a fórmula

λ: média de ocorrências no intervalo considerado (ajuste λ se o intervalo mudar, por exemplo 6 por hora = 3 por meia hora). k: nº de ocorrências desejado. e ≈ 2,71828. “Ou menos” soma de 0 até k.

Exemplo resolvido

Média de λ = 6 clientes por hora. e⁻⁶ = 0,002479.

a) P(X = 3) = e⁻⁶ · 6³ / 3! = 0,002479 · 216 / 6 = 0,0892.

b) P(X ≤ 3) = e⁻⁶ (1 + 6 + 18 + 36) = 0,002479 · 61 = 0,1512 (P(0) = 0,0025; P(1) = 0,0149; P(2) = 0,0446; P(3) = 0,0892).

c) E(X) = 6; DP = √6 = 2,45.

Divergência: o gabarito traz 0,15128 em (b), mas o valor exato é 0,15120. Provável arredondamento. (a) e (c) conferem.

Interpretação

Em uma hora qualquer, a chance de exatamente 3 clientes é de 8,9%; de 3 ou menos, 15,1%. O valor mais comum fica em torno de 6, a média.

Resumo

Contagem em intervalo + taxa média λ → Poisson. Média e variância são iguais a λ.

Aproximação da Binomial pela Poisson

O que é?

Quando uma binomial tem n grande e p muito pequeno (eventos raros), seus resultados ficam muito próximos aos de uma Poisson com λ = n·p, e as contas ficam bem mais simples.

Para que serve?

Evitar potências e combinações enormes em problemas como peças defeituosas em lotes, onde o defeito é raro.

Fórmula

λ = n · p  ⇒  P(X = k) ≈ e−λ · λk / k!

Entendendo a fórmula

Sinais de que cabe a aproximação: o enunciado traz n grande (ex.: ≥ 50), p pequeno (ex.: ≤ 0,1) e λ = np baixo. Os limites exatos variam entre livros; se n for pequeno, prefira a binomial.

Exemplo resolvido

Máquina com 0,2% de peças defeituosas; caixa com 50 peças. n = 50, p = 0,002, λ = 50 · 0,002 = 0,1.

a) P(X = 0) = e⁻⁰·¹ · 0,1⁰ / 0! = e⁻⁰·¹ = 0,9048.

b) P(X = 1) = e⁻⁰·¹ · 0,1 = 0,0905.

Conferência com a binomial exata: P(0) = 0,998⁵⁰ ≈ 0,9048 e P(1) = 50·0,002·0,998⁴⁹ ≈ 0,0907, bem próximos.

Interpretação

Cerca de 90,5% das caixas não têm peça defeituosa e 9,05% têm exatamente uma.

Resumo

Binomial com n grande e p pequeno → calcule λ = np → use Poisson.

Distribuição Normal

O que é?

Distribuição contínua em forma de sino, simétrica em torno da média μ. O desvio padrão σ controla a largura. A área sob a curva entre dois valores é a probabilidade; a área total é 1. Cerca de 68%, 95% e 99,7% dos dados ficam a 1, 2 e 3 desvios da média.

Para que serve?

Modelar medidas como alturas, custos e tempos de produção e calcular a chance de um valor cair em uma faixa.

Fórmula

Z = (X − μ) / σ

Entendendo a fórmula

O escore Z converte X para a normal padrão (média 0, desvio 1), indicando a quantos desvios padrão o valor está da média. Com Z, usa-se a tabela. A tabela “de 0 a z” dá P(0 < Z < z); por simetria, P(−z < Z < 0) é a mesma. Para P(Z > z) com z > 0, calcule 0,5 − P(0 < Z < z). Intervalos que cruzam a média somam as duas áreas.

Exemplo resolvido

Parte 1: X normal, μ = 20, σ = 2.

  • a) P(20 < X < 24): Z de 0 a 2 ⇒ 0,4772.
  • b) P(18 < X < 26): Z de −1 a 3 ⇒ 0,3413 + 0,4987 = 0,8400.
  • c) P(16 < X < 28): Z de −2 a 4 ⇒ 0,4772 + ≈0,5000 = ≈ 0,9772 (a tabela costuma parar em 3,99, e acima disso a área é ≈ 0,5).

Parte 2: custo de produção normal, μ = 50, σ = 4, preço de venda = 60. Há prejuízo se o custo > 60.

Z = (60 − 50)/4 = 2,5. P(X > 60) = 0,5 − 0,4938 = 0,0062 = 0,62%.

Interpretação

Na parte 1, 47,7% dos valores ficam entre a média e 24 (2 desvios acima). Na parte 2, apenas 0,62% das unidades custam mais que o preço de venda: prejuízo é raro.

Resumo

Padronize (Z) → consulte a tabela → ajuste com simetria e com 0,5 (metade da curva) conforme o intervalo pedido.
